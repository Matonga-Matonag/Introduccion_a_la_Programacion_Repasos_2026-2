# Ejercicio 8: Filtrado de números con funciones

## Enunciado

Implementa las siguientes funciones:

1. `pedir_numeros(cantidad)`: **con retorno**. Pide `cantidad` números enteros al usuario con un `for` y devuelve una **lista** con todos ellos, agregados con `append`.

2. `filtrar_mayores(numeros, umbral=10)`: **con retorno**. Devuelve una **lista nueva** con los números de `numeros` que son **estrictamente mayores** que `umbral`. Si no se envía `umbral`, se usa `10`. La lista original no debe cambiar.

3. `mostrar_resultados(numeros, umbral)`: **sin retorno**. Muestra:
   - La lista original completa.
   - La lista filtrada, numerada desde 1 (usando `for` con `range(len(...))`).
   - La cantidad de números filtrados.

El programa principal debe:
- Pedir la cantidad de números con validación (`while`: al menos 1).
- Pedir el `umbral` al usuario.
- Llamar a `pedir_numeros`.
- Llamar a `filtrar_mayores` **con el umbral por defecto** (sin argumento nombrado) y mostrar el resultado.
- Llamar a `mostrar_resultados` con el umbral ingresado por el usuario, usando un **argumento nombrado**: `mostrar_resultados(numeros, umbral=umbral)`.

**Ejemplo:** números `4, 12, 9, 25, 10`, umbral por defecto (`10`):
```
Filtrados (mayores que 10): [12, 25]
```

---

## Resolución paso a paso

### Paso 1 — Identificar tipo y responsabilidad de cada función

| Función | Tipo | Devuelve / Hace |
|---|---|---|
| `pedir_numeros` | Con retorno | Una lista nueva |
| `filtrar_mayores` | Con retorno | Otra lista nueva, filtrada |
| `mostrar_resultados` | Sin retorno | Imprime |

### Paso 2 — Escribir `pedir_numeros`

```python
def pedir_numeros(cantidad):
    numeros = []
    for i in range(cantidad):
        numeros.append(int(input(f"Número {i + 1}: ")))
    return numeros
```

La lista se crea **dentro** de la función y se devuelve al final. Así, el programa principal recibe una lista nueva.

### Paso 3 — Escribir `filtrar_mayores` con parámetro por defecto

```python
def filtrar_mayores(numeros, umbral=10):
    resultado = []
    for x in numeros:
        if x > umbral:
            resultado.append(x)
    return resultado
```

> 💡 `umbral=10` es un parámetro por defecto (visto en el examen 3). Como `numeros` no tiene valor por defecto, va primero.

### Paso 4 — Escribir `mostrar_resultados` sin retorno

```python
def mostrar_resultados(numeros, umbral):
    filtrados = filtrar_mayores(numeros, umbral)

    print(f"Lista original: {numeros}")
    print(f"Mayores que {umbral}:")
    for i in range(len(filtrados)):
        print(f"  {i + 1}. {filtrados[i]}")
    print(f"Cantidad: {len(filtrados)}")
```

> 💡 `mostrar_resultados` llama a `filtrar_mayores`, que es una función con retorno. Esto es composición entre funciones con y sin retorno.

### Paso 5 — Programa principal

```python
def main():
    cantidad = int(input("¿Cuántos números desea ingresar? "))
    while cantidad < 1:
        print("Debe ingresar al menos un número.")
        cantidad = int(input("¿Cuántos números desea ingresar? "))

    umbral = int(input("Ingrese el umbral: "))

    numeros = pedir_numeros(cantidad)

    # Umbral por defecto (10)
    print(f"Filtrados (mayores que 10): {filtrar_mayores(numeros)}")

    # Umbral del usuario, con argumento nombrado
    mostrar_resultados(numeros, umbral=umbral)

main()
```

### Paso 6 — Verificar con `4, 12, 9, 25, 10`

**`filtrar_mayores([4, 12, 9, 25, 10])`** (umbral 10):

| `x` | `x > 10`? | Se agrega |
|---|---|---|
| 4 | No | — |
| 12 | Sí | `[12]` |
| 9 | No | — |
| 25 | Sí | `[12, 25]` |
| 10 | No (no es estrictamente mayor) | — |

Resultado: `[12, 25]` ✅

> ⚠️ `10` no aparece en el resultado porque el enunciado pide **estrictamente mayores**. Si se usara `>=`, sí aparecería.

### Paso 7 — Puntos a revisar

**¿Por qué `filtrar_mayores` no modifica la lista original?**
Porque crea `resultado` y agrega los elementos ahí. Así, `numeros` queda igual, y el programa puede seguir usándola para `mostrar_resultados`.

**¿Por qué `filtrar_mayores(numeros)` no necesita el umbral?**
Porque el parámetro tiene valor por defecto. El programa usa `10` sin necesidad de escribirlo.

**¿Qué pasa si se llama `filtrar_mayores(umbral, numeros)`?**
El código no da error de sintaxis, pero al ejecutarlo se produce un error: `for x in numeros` intenta recorrer un número entero, que no es una secuencia. Por eso el orden de los argumentos importa.

---

> 💡 **Puntos clave de este ejercicio:**
> - Función con retorno que construye y devuelve una lista.
> - Función con retorno que filtra una lista sin modificarla.
> - Parámetro por defecto (`umbral=10`).
> - Argumento nombrado (`umbral=umbral`) en la llamada.
> - Función sin retorno que llama a una función con retorno.
> - Recorrido con `for` y `range(len(...))` para numerar desde 1.
