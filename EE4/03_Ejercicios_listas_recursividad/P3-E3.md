# Ejercicio 10: Inversión de palabras y eliminación de negativos

## Enunciado

Implementa las siguientes funciones:

1. `invertir_cadena(cadena)`: **con retorno**. Devuelve la cadena invertida, recorriéndola con un `for` (**sin usar slicing**).

2. `invertir_palabras(palabras)`: **con retorno**. Recibe una lista de cadenas y devuelve una **lista nueva** con cada palabra invertida. **Debe llamar a `invertir_cadena`** para cada palabra.

   Ejemplo: `["Rojo", "Verde", "Azul"]` → `['ojoR', 'edreV', 'luzA']`

3. `eliminar_negativos(numeros)`: **sin retorno**. Elimina de la lista **recibida** todos los números negativos, **sin crear una lista nueva** y **sin usar `return`**. Debe recorrer la lista de **atrás hacia adelante** para no saltar elementos al eliminar.

El programa principal debe:
- Leer palabras con `input` y agregarlas con `append` hasta que el usuario escriba `"fin"`. Luego mostrar `invertir_palabras` de esa lista.
- Crear la lista `datos = [10, -5, 20, -1, 0, -8]`, llamar a `eliminar_negativos(datos)` y mostrar `datos`.

**Ejemplo de salida:**
```
Palabras invertidas: ['ojoR', 'edreV', 'luzA']
Datos sin negativos: [10, 20, 0]
```

---

## Resolución paso a paso

### Paso 1 — Invertir una cadena sin slicing

Se recorre desde el último índice hasta el primero, con un `range` que retrocede:

```python
def invertir_cadena(cadena):
    respuesta = ""
    for i in range(len(cadena) - 1, -1, -1):
        respuesta = respuesta + cadena[i]
    return respuesta
```

Para `"Rojo"`, `range(3, -1, -1)` genera `3, 2, 1, 0`, así que se concatenan `o`, `j`, `o`, `R`.

### Paso 2 — Invertir cada palabra de la lista

```python
def invertir_palabras(palabras):
    resultado = []
    for p in palabras:
        resultado.append(invertir_cadena(p))
    return resultado
```

`invertir_palabras` no invierte las letras directamente: delega esa tarea a `invertir_cadena`. Esto es composición de funciones con retorno.

### Paso 3 — Eliminar negativos sin crear una lista nueva

Como el enunciado no permite `return`, la función debe modificar la lista original. Si se recorriera de **adelante hacia atrás**, al eliminar un elemento los siguientes se corren una posición y el bucle se los saltaría:

```python
# ❌ Recorrido de adelante hacia atrás
datos = [-1, -2, 3]
for i in range(len(datos)):
    if datos[i] < 0:
        datos.pop(i)
# Resultado: [-2, 3]  → el -2 se saltó
```

Recorriendo de atrás hacia adelante, los elementos que quedan delante del eliminado no cambian de posición:

```python
def eliminar_negativos(numeros):
    for i in range(len(numeros) - 1, -1, -1):
        if numeros[i] < 0:
            numeros.pop(i)
```

### Paso 4 — Programa principal

```python
def main():
    palabras = []
    palabra = input("Ingrese una palabra (fin para terminar): ")
    while palabra != "fin":
        palabras.append(palabra)
        palabra = input("Ingrese una palabra (fin para terminar): ")

    print(f"Palabras invertidas: {invertir_palabras(palabras)}")

    datos = [10, -5, 20, -1, 0, -8]
    eliminar_negativos(datos)
    print(f"Datos sin negativos: {datos}")

main()
```

### Paso 5 — Verificar `invertir_cadena("Rojo")`

| `i` | `cadena[i]` | `respuesta` |
|---|---|---|
| inicio | — | `""` |
| 3 | `o` | `"o"` |
| 2 | `j` | `"oj"` |
| 1 | `o` | `"ojo"` |
| 0 | `R` | `"ojoR"` ✅ |

### Paso 6 — Verificar `eliminar_negativos([10, -5, 20, -1, 0, -8])`

Recorrido de atrás hacia adelante (`i` va de `5` a `0`):

| `i` | `numeros[i]` | ¿Negativo? | Acción | Lista resultante |
|---|---|---|---|---|
| 5 | −8 | Sí | `pop(5)` | `[10, -5, 20, -1, 0]` |
| 4 | 0 | No | — | — |
| 3 | −1 | Sí | `pop(3)` | `[10, -5, 20, 0]` |
| 2 | 20 | No | — | — |
| 1 | −5 | Sí | `pop(1)` | `[10, 20, 0]` |
| 0 | 10 | No | — | — |

Resultado: `[10, 20, 0]` ✅

### Paso 7 — Puntos a revisar

**¿Por qué `eliminar_negativos` no tiene `return`?**
Porque modifica la lista recibida. Como las listas son mutables, el cambio se ve en el programa principal sin necesidad de devolver nada.

**¿Por qué `invertir_cadena` no usa `[::-1]`?**
Porque el enunciado pide recorrer la cadena con un `for`. El slicing es un atajo válido en otras situaciones, pero aquí no se permite.

**¿Qué pasaría con `invertir_palabras([])`?**
La función devuelve `[]`, porque el `for` no se ejecuta. No necesita un caso especial.

**¿Por qué en el programa principal se usa `palabra != "fin"` y no `palabra == "fin"`?**
Porque el `while` debe continuar mientras la palabra **no** sea `"fin"`. Es el mismo patrón de centinela de los exámenes anteriores.

> - Función sin retorno que modifica una lista recibida.
> - Recorrido de atrás hacia adelante al eliminar elementos.
> - Centinela con texto (`"fin"`) y `while`.
> - Función con `append` dentro de un `for` para construir una lista nueva.
