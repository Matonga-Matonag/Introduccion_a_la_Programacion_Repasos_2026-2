# Ejercicio 9: Segundo mayor y diferencias consecutivas

## Enunciado

Implementa las siguientes funciones:

1. `eliminar_duplicados(lista)`: **con retorno**. Devuelve una **lista nueva** con los elementos de `lista` sin repetidos, en el mismo orden de aparición. Usa `in` y `append`.

2. `segundo_mayor(numeros)`: **con retorno**. Devuelve el **segundo valor más grande** de la lista, **sin contar repetidos**. Si no existe (lista con menos de 2 valores distintos), devuelve `None`. **Debe llamar a `eliminar_duplicados`** y luego usar `sorted` con `reverse=True`.

3. `diferencias_consecutivas(numeros)`: **con retorno**. Devuelve una lista nueva con la diferencia entre cada elemento y el anterior: `numeros[i+1] − numeros[i]`. Si la lista tiene menos de 2 elementos, devuelve `[]`.

4. `mostrar_analisis(numeros)`: **sin retorno**. Muestra el segundo mayor (o `"No existe"` si es `None`) y la lista de diferencias consecutivas.

El programa principal debe pedir números enteros uno por uno y **agregarlos a una lista con `append`**, hasta que el usuario ingrese `0`. Luego llama a `mostrar_analisis`.

**Ejemplos:**

| Lista | `segundo_mayor` | `diferencias_consecutivas` |
|---|---|---|
| `[12, 35, 1, 10, 34, 1, 35]` | `34` | `[23, -34, 9, 24, -33, 34]` |
| `[7, 7, 7]` | `None` | `[0, 0]` |
| `[4, 5, 8, 9, 6, 10]` | `9` | `[1, 3, 1, -3, 4]` |
| `[5]` | `None` | `[]` |

---

## Resolución paso a paso

### Paso 1 — Eliminar duplicados con `in`

```python
def eliminar_duplicados(lista):
    unicos = []
    for x in lista:
        if x not in unicos:
            unicos.append(x)
    return unicos
```

`x not in unicos` combina el operador `not` con `in`, ambos vistos en clase.

### Paso 2 — Segundo mayor

El segundo mayor se obtiene después de quitar repetidos, ordenar de mayor a menor y tomar la **posición 1**:

```python
def segundo_mayor(numeros):
    unicos = eliminar_duplicados(numeros)
    if len(unicos) < 2:
        return None
    ordenados = sorted(unicos, reverse=True)
    return ordenados[1]
```

> ⚠️ Sin `eliminar_duplicados`, para `[35, 35, 34]` el resultado sería `35` (el mayor repetido), no `34`. Por eso quitar repetidos es necesario.

### Paso 3 — Diferencias consecutivas

Se recorre hasta el penúltimo índice, porque cada diferencia usa el elemento actual y el siguiente:

```python
def diferencias_consecutivas(numeros):
    resultado = []
    for i in range(len(numeros) - 1):
        resultado.append(numeros[i + 1] - numeros[i])
    return resultado
```

Para `[5]`, `range(0)` no genera valores, así que se devuelve `[]` sin necesidad de un caso especial.

### Paso 4 — Función sin retorno

```python
def mostrar_analisis(numeros):
    sm = segundo_mayor(numeros)
    if sm is None:
        print("Segundo mayor: No existe")
    else:
        print(f"Segundo mayor: {sm}")
    print(f"Diferencias consecutivas: {diferencias_consecutivas(numeros)}")
```

> ⚠️ Para comparar con `None` se usa `is None`, no `== None`. Es la forma recomendada en Python.

### Paso 5 — Programa principal

```python
def main():
    numeros = []
    n = int(input("Ingrese un número (0 para terminar): "))
    while n != 0:
        numeros.append(n)
        n = int(input("Ingrese un número (0 para terminar): "))

    mostrar_analisis(numeros)

main()
```

### Paso 6 — Verificar `[12, 35, 1, 10, 34, 1, 35]`

**`eliminar_duplicados`:** `[12, 35, 1, 10, 34]`

**`segundo_mayor`:** ordenados de mayor a menor `[35, 34, 12, 10, 1]` → posición 1 → `34` ✅

**`diferencias_consecutivas`:**

| `i` | `numeros[i]` | `numeros[i+1]` | Diferencia |
|---|---|---|---|
| 0 | 12 | 35 | 23 |
| 1 | 35 | 1 | −34 |
| 2 | 1 | 10 | 9 |
| 3 | 10 | 34 | 24 |
| 4 | 34 | 1 | −33 |
| 5 | 1 | 35 | 34 |

Resultado: `[23, -34, 9, 24, -33, 34]` ✅

### Paso 7 — Verificar los casos borde

- `[7, 7, 7]`: `eliminar_duplicados` → `[7]`. Como `len < 2`, devuelve `None`. ✅
- `[5]`: `diferencias_consecutivas` → `[]`. ✅

### Paso 8 — Puntos a revisar

**¿Por qué `segundo_mayor` llama a `eliminar_duplicados`?**
Porque el enunciado pide el segundo valor distinto, no la segunda posición del ordenamiento. Esto es composición de funciones con retorno.

**¿Por qué `diferencias_consecutivas` usa `range(len(numeros) - 1)`?**
Porque el último elemento no tiene siguiente. El rango de índices llega hasta el penúltimo.

**¿Por qué `mostrar_analisis` guarda `segundo_mayor` en una variable?**
Para no llamar a la función dos veces: una para comparar con `None` y otra para imprimir el valor.

> 💡 **Puntos clave de este ejercicio:**
> - Función con retorno que filtra duplicados con `in` y `not`.
> - Composición: `segundo_mayor` llama a `eliminar_duplicados`.
> - `sorted(..., reverse=True)` sin modificar la lista.
> - Comparación con `None` usando `is`.
> - Recorrido de pares consecutivos con `range(len(lista) - 1)`.
> - Función sin retorno que llama a dos funciones con retorno.
> - Validación de la entrada mediante un centinela (`0`).
