# Ejercicio 7: Búsqueda, conteo y copias de una lista de nombres

## Enunciado

Implementa un programa que trabaje con una lista de nombres de personas. El programa debe:

1. Pedir la cantidad de nombres `n` (validación con `while`: al menos 1) y leer cada nombre con `append`.

2. **Búsqueda secuencial:** pedir un nombre a buscar y recorrer la lista con un `while` que se detenga al encontrarlo o al llegar al final. Mostrar la posición de la **primera aparición** (numerada desde 0) o `"No encontrado"`. No se debe usar `in` para esta parte.

3. **Conteo con bucles anidados:** mostrar cuántas veces aparece **cada nombre distinto**. Para ello, por cada posición `i` se cuenta con un `for` interno cuántas veces aparece `nombres[i]` en toda la lista. Cada nombre distinto debe mostrarse **una sola vez**: se imprime solo en su primera aparición. Para saber si un nombre ya apareció antes, se revisan con un `for` interno las posiciones anteriores a `i`.

4. **Alias y copias:** crear `copia = nombres.copy()`, agregar el nombre `"Zoe"` **solo a la copia** y mostrar ambas listas. La original no debe cambiar.

5. **Slicing:** mostrar los dos últimos nombres de la lista original con `nombres[-2:]`. Si la lista tiene un solo nombre, mostrar ese único nombre.

**Ejemplo con nombres `["Ana", "Luis", "Ana", "Rosa"]`, búsqueda de `"Luis"`:**
```
"Luis" encontrado en la posición 1
Ana: 2 veces
Luis: 1 vez
Rosa: 1 vez
Original: ['Ana', 'Luis', 'Ana', 'Rosa']
Copia: ['Ana', 'Luis', 'Ana', 'Rosa', 'Zoe']
Últimos dos nombres: ['Ana', 'Rosa']
```

---

## Resolución paso a paso

### Paso 1 — Llenar la lista

```python
n = int(input("¿Cuántos nombres? "))
while n < 1:
    print("Debe ingresar al menos un nombre.")
    n = int(input("¿Cuántos nombres? "))

nombres = []
for i in range(n):
    nombres.append(input(f"Nombre {i + 1}: "))
```

### Paso 2 — Búsqueda secuencial con `while`

El orden de las condiciones es importante: primero se verifica que la posición esté dentro de la lista.

```python
buscado = input("Nombre a buscar: ")

pos = 0
while pos < len(nombres) and nombres[pos] != buscado:
    pos = pos + 1

if pos < len(nombres):
    print(f'"{buscado}" encontrado en la posición {pos}')
else:
    print("No encontrado")
```

> ⚠️ Si se invirtiera el orden, `nombres[pos]` podría acceder a una posición que no existe. Python lo evita porque `and` se evalúa de izquierda a derecha y se detiene en cuanto una condición es falsa.

### Paso 3 — Conteo con bucles anidados

Para cada posición `i`, un `for` interno revisa si `nombres[i]` apareció antes. Si no apareció, otro `for` interno cuenta sus apariciones totales:

```python
for i in range(len(nombres)):
    repetido = False
    for j in range(i):                        # revisar posiciones anteriores
        if nombres[j] == nombres[i]:
            repetido = True

    if not repetido:                          # solo la primera aparición
        cuenta = 0
        for j in range(len(nombres)):         # contar en toda la lista
            if nombres[j] == nombres[i]:
                cuenta = cuenta + 1
        print(f"{nombres[i]}: {cuenta} veces")
```

> 💡 Cuando `i = 0`, `range(0)` no genera valores y `repetido` queda en `False`. Así, la primera aparición de cada nombre siempre se procesa.

### Paso 4 — Alias y copias

```python
copia = nombres.copy()
copia.append("Zoe")

print(f"Original: {nombres}")
print(f"Copia: {copia}")
```

Si se hubiera escrito `copia = nombres` (sin `copy()`), ambos nombres apuntarían a la **misma** lista y la original también cambiaría.

### Paso 5 — Slicing

```python
if len(nombres) >= 2:
    print(f"Últimos dos nombres: {nombres[-2:]}")
else:
    print(f"Único nombre: {nombres}")
```

`nombres[-2:]` toma desde la penúltima posición hasta el final.

### Paso 6 — Programa completo

```python
def main():
    n = int(input("¿Cuántos nombres? "))
    while n < 1:
        print("Debe ingresar al menos un nombre.")
        n = int(input("¿Cuántos nombres? "))

    nombres = []
    for i in range(n):
        nombres.append(input(f"Nombre {i + 1}: "))

    buscado = input("Nombre a buscar: ")
    pos = 0
    while pos < len(nombres) and nombres[pos] != buscado:
        pos = pos + 1
    if pos < len(nombres):
        print(f'"{buscado}" encontrado en la posición {pos}')
    else:
        print("No encontrado")

    for i in range(len(nombres)):
        repetido = False
        for j in range(i):
            if nombres[j] == nombres[i]:
                repetido = True
        if not repetido:
            cuenta = 0
            for j in range(len(nombres)):
                if nombres[j] == nombres[i]:
                    cuenta = cuenta + 1
            print(f"{nombres[i]}: {cuenta} veces")

    copia = nombres.copy()
    copia.append("Zoe")
    print(f"Original: {nombres}")
    print(f"Copia: {copia}")

    if len(nombres) >= 2:
        print(f"Últimos dos nombres: {nombres[-2:]}")
    else:
        print(f"Único nombre: {nombres}")

main()
```

### Paso 7 — Verificar con `["Ana", "Luis", "Ana", "Rosa"]`

**Búsqueda de "Luis":** `pos` avanza `0` (Ana ≠ Luis), luego `1` (Luis = Luis) → "encontrado en la posición 1" ✅

**Conteo:**

| `i` | `nombres[i]` | ¿Apareció antes? (`for j in range(i)`) | Cuenta | Se imprime |
|---|---|---|---|---|
| 0 | Ana | No | 2 | Sí |
| 1 | Luis | No | 1 | Sí |
| 2 | Ana | Sí (en `j = 0`) | — | No |
| 3 | Rosa | No | 1 | Sí |

**Copia:** `copia` tiene 5 elementos; `nombres` sigue con 4 ✅

**Slicing:** `nombres[-2:]` → `['Ana', 'Rosa']` ✅

### Paso 8 — Puntos a revisar

**¿Por qué la búsqueda no usa `in`?**
Porque el enunciado pide una búsqueda secuencial con `while`. Así se ve cómo funciona la búsqueda por dentro: se recorre la lista hasta encontrar el elemento.

**¿Por qué el conteo revisa las posiciones anteriores?**
Para imprimir cada nombre una sola vez. Si `nombres[i]` ya apareció en una posición menor, esa primera aparición ya se procesó y se omite.

**¿Cuántas comparaciones hace el conteo?**
Para cada posición `i`, se recorre hasta `i` posiciones anteriores y toda la lista. Con `n` nombres, esto es del orden de `n × n` comparaciones: un ejemplo de bucles anidados sobre una lista.

**¿Qué pasa si `copia = nombres` y luego `copia.append("Zoe")`?**
Ambas variables apuntan a la misma lista, así que `nombres` también incluiría `"Zoe"`. Por eso se usa `copy()`.
