# Ejercicio 5: Ranking de notas

## Enunciado

Un docente registra las notas de su curso en una lista. Implementa un programa que:

1. Pida la cantidad de alumnos `n` (validación con `while`: debe ser al menos 1).
2. Para cada alumno, pida su nota con validación con `while` (la nota debe estar entre 0 y 20). Cada nota válida se agrega a la lista con `append`.
3. Al terminar, muestre:
   - La lista de notas ingresadas, en el orden original, numerada desde 1 (usando `for` con `range(len(...))`).
   - La **nota máxima** y la **posición de su primera aparición**, numerada desde 1 (usando `max` y un `while`).
   - La **nota mínima** (usando `min`).
   - El **promedio** redondeado a 2 decimales (usando `sum` y `len`).
   - Una lista de las notas **ordenadas de mayor a menor**, sin modificar la lista original (usando `sorted` con `reverse=True`).
   - La **cantidad de aprobados** (nota mayor o igual a 11), recorriendo la lista con un `for`, sin usar `sum` para contar.

**Ejemplo con notas 12, 8, 15, 15, 20:**
```
1. 12
2. 8
3. 15
4. 15
5. 20
Nota máxima: 20 (posición 5)
Nota mínima: 8
Promedio: 14.0
Ordenadas de mayor a menor: [20, 15, 15, 12, 8]
Aprobados: 4
```

---

## Resolución paso a paso

### Paso 1 — Identificar las operaciones sobre la lista

| Necesito... | Herramienta |
|---|---|
| Guardar las notas | `lista = []` y `append` |
| Mostrar con posición | `for i in range(len(lista))` y `lista[i]` |
| Mayor | `max(lista)` |
| Posición del mayor | `while` que recorre hasta encontrarlo |
| Menor | `min(lista)` |
| Promedio | `sum(lista) / len(lista)` |
| Ordenadas sin modificar la original | `sorted(lista, reverse=True)` |
| Contar aprobados | `for` con un contador |

### Paso 2 — Llenar la lista con validación

Para cada alumno, la nota se valida con un `while` **dentro** del `for`:

```python
notas = []
for i in range(n):
    nota = float(input(f"Nota del alumno {i + 1}: "))
    while nota < 0 or nota > 20:
        print("Nota inválida. Debe estar entre 0 y 20.")
        nota = float(input(f"Nota del alumno {i + 1}: "))
    notas.append(nota)
```

### Paso 3 — Mostrar la lista numerada

El `range` recorre las posiciones, y se muestra `i + 1` para numerar desde 1:

```python
for i in range(len(notas)):
    print(f"{i + 1}. {notas[i]}")
```

### Paso 4 — Mayor, posición del mayor, menor y promedio

Para encontrar la posición de la primera aparición del máximo, se usa un `while` que avanza hasta encontrarlo. Como el máximo está en la lista, el `while` siempre se detiene:

```python
maxima = max(notas)
pos = 0
while notas[pos] != maxima:
    pos = pos + 1
posicion = pos + 1          # +1 para numerar desde 1

minima = min(notas)
promedio = sum(notas) / len(notas)
```

> ⚠️ El `while` se detiene en la **primera** aparición del máximo. Como `15` aparece dos veces, si el máximo fuera `15`, se mostraría la posición de la primera.

### Paso 5 — Ordenar sin modificar la original

```python
ordenadas = sorted(notas, reverse=True)
print(notas)        # la original sigue igual
print(ordenadas)    # la nueva, de mayor a menor
```

### Paso 6 — Contar aprobados con un `for`

```python
aprobados = 0
for nota in notas:
    if nota >= 11:
        aprobados = aprobados + 1
```

### Paso 7 — Programa completo

```python
def main():
    n = int(input("¿Cuántos alumnos hay? "))
    while n < 1:
        print("Debe haber al menos un alumno.")
        n = int(input("¿Cuántos alumnos hay? "))

    notas = []
    for i in range(n):
        nota = float(input(f"Nota del alumno {i + 1}: "))
        while nota < 0 or nota > 20:
            print("Nota inválida. Debe estar entre 0 y 20.")
            nota = float(input(f"Nota del alumno {i + 1}: "))
        notas.append(nota)

    for i in range(len(notas)):
        print(f"{i + 1}. {notas[i]}")

    maxima = max(notas)
    pos = 0
    while notas[pos] != maxima:
        pos = pos + 1
    print(f"Nota máxima: {maxima} (posición {pos + 1})")

    print(f"Nota mínima: {min(notas)}")
    print(f"Promedio: {round(sum(notas) / len(notas), 2)}")
    print(f"Ordenadas de mayor a menor: {sorted(notas, reverse=True)}")

    aprobados = 0
    for nota in notas:
        if nota >= 11:
            aprobados = aprobados + 1
    print(f"Aprobados: {aprobados}")

main()
```

### Paso 8 — Verificar con 12, 8, 15, 15, 20

| Operación | Cálculo | Resultado |
|---|---|---|
| Máximo | `max` | `20` |
| Posición del máximo | `while` se detiene en `pos = 4` → `4 + 1` | `5` |
| Mínimo | `min` | `8` |
| Promedio | `70 / 5` | `14.0` |
| Ordenadas | `sorted(..., reverse=True)` | `[20, 15, 15, 12, 8]` |
| Aprobados (≥ 11) | `12, 15, 15, 20` | `4` |

✅

### Paso 9 — Puntos a revisar

**¿Por qué `pos + 1` al mostrar la posición?**
El `while` cuenta desde `0`, pero el enunciado pide numerar desde `1`, igual que en la lista impresa.

**¿Por qué el `while` del máximo no se sale del rango?**
Porque el máximo siempre está en la lista, así que la condición `notas[pos] != maxima` se vuelve falsa antes de que `pos` llegue al final.

**¿Por qué se usa `sorted` y no `sort`?**
El enunciado pide mantener la lista original. `sort()` la modificaría y no devolvería nada.

**¿Por qué el conteo de aprobados no usa `sum`?**
Porque el enunciado pide recorrer la lista con un `for`. Un contador sirve cuando la condición es más compleja que un valor directo.
