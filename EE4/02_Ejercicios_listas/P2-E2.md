# Ejercicio 6: Gestión de inventario con menú

## Enunciado

Un almacén lleva su inventario en una lista de nombres de productos. Implementa un programa con un **menú** que se repita hasta que el usuario elija salir (`0`). El inventario empieza **vacío**.

El menú debe tener las siguientes opciones:

| Opción | Acción | Método a usar |
|---|---|---|
| 1 | Agregar un producto **al final** | `append` |
| 2 | Agregar un producto **al inicio** | `insert(0, ...)` |
| 3 | Eliminar un producto por nombre | `in` y `remove` |
| 4 | Eliminar el **último** producto y mostrarlo | `pop` |
| 5 | Ordenar el inventario alfabéticamente | `sort` |
| 6 | Mostrar el inventario numerado desde 1 | `for` con `range(len(...))` |
| 0 | Salir | — |

Reglas adicionales:
- Si se intenta agregar un producto que **ya existe**, mostrar `"Ya existe en el inventario."` y no agregarlo.
- Si se intenta eliminar un producto que **no existe**, mostrar `"No se encuentra ese producto."`.
- Si se intenta usar `pop` (opción 4) con el inventario **vacío**, mostrar `"El inventario está vacío."`.
- Si se ingresa una opción fuera del menú, mostrar `"Opción no válida."`.

---

## Resolución paso a paso

### Paso 1 — Diseñar la estructura del programa

```
inventario = []
opcion = -1
while opcion != 0:
    mostrar menú
    leer opcion
    if opcion == 1: ...
    elif opcion == 2: ...
    ...
    elif opcion != 0: "Opción no válida"
```

Se usa `opcion = -1` para que el `while` arranque sin que el usuario haya elegido nada.

### Paso 2 — Agregar al final y al inicio

```python
nombre = input("Nombre del producto: ")
if nombre in inventario:
    print("Ya existe en el inventario.")
else:
    inventario.append(nombre)        # opción 1
```

Para la opción 2 se usa `inventario.insert(0, nombre)` con la misma verificación de `in`.

### Paso 3 — Eliminar por nombre: verificar antes de `remove`

`remove` produce un error si el elemento no está. Por eso se verifica primero con `in`:

```python
nombre = input("Producto a eliminar: ")
if nombre in inventario:
    inventario.remove(nombre)
else:
    print("No se encuentra ese producto.")
```

### Paso 4 — Eliminar el último con `pop`

`pop()` devuelve el elemento eliminado, así que se puede guardar y mostrar. Pero **si la lista está vacía**, `pop` produce un error:

```python
if len(inventario) == 0:
    print("El inventario está vacío.")
else:
    eliminado = inventario.pop()
    print(f"Se eliminó: {eliminado}")
```

### Paso 5 — Ordenar y mostrar numerado

```python
inventario.sort()                       # opción 5: modifica la lista

for i in range(len(inventario)):        # opción 6
    print(f"{i + 1}. {inventario[i]}")
```

### Paso 6 — Programa completo

```python
def main():
    inventario = []
    opcion = -1

    while opcion != 0:
        print("\n1. Agregar al final")
        print("2. Agregar al inicio")
        print("3. Eliminar por nombre")
        print("4. Eliminar el último")
        print("5. Ordenar")
        print("6. Mostrar inventario")
        print("0. Salir")
        opcion = int(input("Elija una opción: "))

        if opcion == 1:
            nombre = input("Nombre del producto: ")
            if nombre in inventario:
                print("Ya existe en el inventario.")
            else:
                inventario.append(nombre)

        elif opcion == 2:
            nombre = input("Nombre del producto: ")
            if nombre in inventario:
                print("Ya existe en el inventario.")
            else:
                inventario.insert(0, nombre)

        elif opcion == 3:
            nombre = input("Producto a eliminar: ")
            if nombre in inventario:
                inventario.remove(nombre)
            else:
                print("No se encuentra ese producto.")

        elif opcion == 4:
            if len(inventario) == 0:
                print("El inventario está vacío.")
            else:
                eliminado = inventario.pop()
                print(f"Se eliminó: {eliminado}")

        elif opcion == 5:
            inventario.sort()

        elif opcion == 6:
            for i in range(len(inventario)):
                print(f"{i + 1}. {inventario[i]}")

        elif opcion != 0:
            print("Opción no válida.")

    print("Fin del programa.")

main()
```

### Paso 7 — Traza de una sesión

| Acción | Estado de `inventario` |
|---|---|
| Inicio | `[]` |
| 1 → "papas" | `['papas']` |
| 1 → "leche" | `['papas', 'leche']` |
| 2 → "arroz" | `['arroz', 'papas', 'leche']` |
| 1 → "papas" | sin cambios: "Ya existe en el inventario." |
| 5 (ordenar) | `['arroz', 'leche', 'papas']` |
| 3 → "pan" | sin cambios: "No se encuentra ese producto." |
| 4 (pop) | se elimina `'papas'` → `['arroz', 'leche']` |

### Paso 8 — Puntos a revisar

**¿Por qué `opcion = -1` antes del `while`?**
La condición `opcion != 0` se evalúa antes de la primera iteración. El valor `-1` garantiza que el menú se muestre al menos una vez.

**¿Por qué se usa `in` antes de `remove` y `pop`?**
`remove` produce un error si el elemento no existe, y `pop` lo produce si la lista está vacía. Verificar antes de llamar al método evita que el programa se detenga.

**¿Por qué `sort` no se usa dentro de `print`?**
Porque `sort()` no devuelve la lista: devuelve `None`. Por eso se llama en una línea aparte, y después se recorre la lista ya ordenada.
