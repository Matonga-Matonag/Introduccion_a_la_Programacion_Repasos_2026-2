# Ejercicio 1: Serie alternada de cuadrados

## Enunciado

Se define la serie:

```
S(n) = 1² − 2² + 3² − 4² + ... ± n²
```

Los términos de posición impar se **suman** y los de posición par se **restan**. Por ejemplo, `S(4) = 1 − 4 + 9 − 16 = −10`.

Implementa las siguientes funciones:

1. `es_impar(n)`: **con retorno booleano**. Devuelve `True` si `n` es impar.
2. `serie_alternada(n)`: **con retorno y recursiva**. Calcula `S(n)` sin usar bucles. Debe usar `es_impar` para decidir el signo del término `n²`. El caso base es `S(0) = 0`.

El programa principal debe pedir `n` con validación (`while`: si `n < 1`, volver a pedirlo) e imprimir `S(n)` con el formato `S(n) = resultado`.

**Ejemplo:** `n = 4` → `S(4) = -10`

---

## Resolución paso a paso

### Paso 1 — Escribir la relación de recurrencia

Para calcular `S(n)` a partir de `S(n − 1)`:

```
S(n) = S(n − 1) + n²    si n es impar
S(n) = S(n − 1) − n²    si n es par
```

### Paso 2 — Identificar el caso base y el caso recursivo

- **Caso base:** `S(0) = 0`
- **Caso recursivo:** `S(n) = S(n − 1) ± n²`, donde el signo depende de la paridad de `n`.

### Paso 3 — Escribir las funciones

```python
def es_impar(n):
    return n % 2 == 1

def serie_alternada(n):
    if n == 0:                                      # caso base
        return 0
    if es_impar(n):                                 # signo +
        return serie_alternada(n - 1) + n ** 2
    return serie_alternada(n - 1) - n ** 2          # signo -
```

> 💡 `es_impar(n)` se llama dentro de la función recursiva: es una función booleana usada en un `if`, combinada con recursión.

### Paso 4 — Programa principal

```python
def main():
    n = int(input("Ingrese n: "))
    while n < 1:
        print("n debe ser al menos 1.")
        n = int(input("Ingrese n: "))

    print(f"S({n}) = {serie_alternada(n)}")

main()
```

### Paso 5 — Traza de `serie_alternada(4)`

| Llamada | `es_impar(n)` | Operación | Retorno |
|---|---|---|---|
| `serie_alternada(4)` | No | `serie_alternada(3) − 16` | pendiente |
| `serie_alternada(3)` | Sí | `serie_alternada(2) + 9` | pendiente |
| `serie_alternada(2)` | No | `serie_alternada(1) − 4` | pendiente |
| `serie_alternada(1)` | Sí | `serie_alternada(0) + 1` | pendiente |
| `serie_alternada(0)` | — | caso base | `0` |

Subida: `0 + 1 = 1` → `1 − 4 = −3` → `−3 + 9 = 6` → `6 − 16 = −10` ✅

### Paso 6 — Verificar otros valores

- `S(1) = 1`
- `S(2) = 1 − 4 = −3`
- `S(3) = −3 + 9 = 6`
- `S(5) = −10 + 25 = 15`

### Paso 7 — Puntos a revisar

**¿Por qué `es_impar` no imprime nada?**
Porque su tarea es responder una pregunta (sí o no). La función recursiva la usa dentro de un `if`, como cualquier condición booleana.

**¿Por qué el caso base es `S(0) = 0`?**
Porque una serie sin términos vale `0`. Así, la regla recursiva se aplica igual a todos los términos desde el primero. Con caso base `n == 1` (devolviendo `1`) también se obtiene el resultado correcto, pero el caso `n == 0` es el más natural.

> 💡 **Puntos clave de este ejercicio:**
> - Recursión con dos ramas que dependen de una condición (`if` dentro de la función recursiva).
> - Función booleana usada como condición dentro de otra función.
> - Operador `**` para elevar al cuadrado.
> - Validación con `while` en `main`.
