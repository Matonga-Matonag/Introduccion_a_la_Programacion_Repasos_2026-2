# Ejercicio 4: Conversión de decimal a binario

## Enunciado

Implementa un programa que convierta un número entero decimal `n` (mayor o igual que 0) a su representación en **binario**, usando **recursión**.

El método consiste en dividir `n` entre 2 sucesivamente: el residuo de cada división es un dígito binario, y los dígitos se leen de **último a primero** (de la última división a la primera).

Implementa las siguientes funciones:

1. `decimal_a_binario(n)`: **con retorno y recursiva**. Devuelve el binario de `n` como **cadena de texto**. Sin bucles. El caso base es `n < 2`.

2. `contar_unos(n)`: **con retorno y recursiva**. Devuelve cuántos dígitos `1` tiene la representación binaria de `n`. Sin convertir a cadena: debe usar `%` y `//`.

El programa principal debe pedir `n` con validación (si `n < 0`, volver a pedirlo) e imprimir ambos resultados.

**Ejemplo con `n = 13`:**
```
Binario de 13: 1101
Cantidad de unos: 3
```

---

## Resolución paso a paso

### Paso 1 — Entender el método de divisiones sucesivas

Para `n = 13`:

| División | Cociente (`n // 2`) | Residuo (`n % 2`) |
|---|---|---|
| 13 ÷ 2 | 6 | 1 |
| 6 ÷ 2 | 3 | 0 |
| 3 ÷ 2 | 1 | 1 |
| 1 ÷ 2 | 0 | 1 |

Los residuos, leídos de abajo hacia arriba, forman `1101`.

### Paso 2 — Relación recursiva

Si `n ≥ 2`, el binario de `n` es el binario de `n // 2` seguido del dígito `n % 2`:

```
binario(n) = binario(n // 2) + str(n % 2)
```

El caso base es `n < 2`: el binario de `0` es `"0"` y el de `1` es `"1"`.

### Paso 3 — Escribir `decimal_a_binario`

```python
def decimal_a_binario(n):
    if n < 2:                                           # caso base
        return str(n)
    return decimal_a_binario(n // 2) + str(n % 2)       # caso recursivo
```

> 💡 `str(n % 2)` convierte el residuo (un entero) a cadena para poder concatenarlo con `+`.

### Paso 4 — Escribir `contar_unos`

Contar los `1` de un número en binario equivale a sumar sus residuos en base 2:

```
unos(n) = unos(n // 2) + n % 2
```

```python
def contar_unos(n):
    if n == 0:                          # caso base
        return 0
    return n % 2 + contar_unos(n // 2)  # caso recursivo
```

### Paso 5 — Programa principal

```python
def main():
    n = int(input("Ingrese un número entero (>= 0): "))
    while n < 0:
        print("El número no puede ser negativo.")
        n = int(input("Ingrese un número entero (>= 0): "))

    print(f"Binario de {n}: {decimal_a_binario(n)}")
    print(f"Cantidad de unos: {contar_unos(n)}")

main()
```

### Paso 6 — Traza de `decimal_a_binario(13)`

| Llamada | `n < 2`? | Operación | Retorno parcial |
|---|---|---|---|
| `decimal_a_binario(13)` | No | `decimal_a_binario(6) + "1"` | pendiente |
| `decimal_a_binario(6)` | No | `decimal_a_binario(3) + "0"` | pendiente |
| `decimal_a_binario(3)` | No | `decimal_a_binario(1) + "1"` | pendiente |
| `decimal_a_binario(1)` | Sí | caso base | `"1"` |

Subida: `"1"` → `"1" + "1"` = `"11"` → `"11" + "0"` = `"110"` → `"110" + "1"` = `"1101"` ✅

### Paso 7 — Traza de `contar_unos(13)`

`13 % 2 = 1` + `contar_unos(6)`
→ `6 % 2 = 0` + `contar_unos(3)`
→ `3 % 2 = 1` + `contar_unos(1)`
→ `1 % 2 = 1` + `contar_unos(0)`
→ `contar_unos(0) = 0`

Total: `1 + 0 + 1 + 1 + 0 = 3` ✅

### Paso 8 — Casos borde

- `n = 0`: `decimal_a_binario(0)` devuelve `"0"` (caso base). `contar_unos(0)` devuelve `0`.
- `n = 1`: devuelve `"1"` y `1`.

### Paso 9 — Puntos a revisar

**¿Por qué `decimal_a_binario` devuelve una cadena y no un número?**
Porque el binario `1101` como número entero (`1101`) sería diferente del valor binario `13`. Una cadena conserva los dígitos tal como deben leerse.

**¿Por qué el orden de la concatenación es `binario(n // 2) + str(n % 2)`?**
El primer residuo que se calcula es el dígito menos significativo, es decir, el de la derecha. La llamada recursiva resuelve primero los dígitos de la izquierda, así que el residuo actual debe concatenarse al final.

**¿Por qué `contar_unos` no usa cadenas?**
Porque el enunciado pide usar `%` y `//`. Esto muestra que la misma descomposición sirve para obtener el número de dígitos `1` sin construir el binario.

---

> 💡 **Puntos clave de este ejercicio:**
> - Recursión con dos resultados distintos: una cadena (`decimal_a_binario`) y un entero (`contar_unos`).
> - Operadores `//` y `%` para descomponer el número.
> - Conversión de entero a cadena con `str()` para concatenar.
> - Casos base `n < 2` y `n == 0`.
> - Validación de entrada con `while` en `main`.
