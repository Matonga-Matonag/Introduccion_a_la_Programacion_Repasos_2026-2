# Ejercicio 2: Serie armónica y umbral

## Enunciado

Se define la serie armónica de orden `n`:

```
H(n) = 1 + 1/2 + 1/3 + ... + 1/n
```

Implementa las siguientes funciones:

1. `armonica(n)`: **con retorno y recursiva**. Devuelve `H(n)` como número decimal. Sin bucles. El caso base es `H(1) = 1`.

2. `supera_limite(valor, limite=3)`: **con retorno booleano**. Devuelve `True` si `valor` es mayor que `limite`. El límite por defecto es `3`.

El programa principal debe:
- Pedir `n` con validación (si `n < 1`, volver a pedirlo).
- Mostrar `H(n)` redondeado a **4 decimales** con `round()`.
- Indicar si `H(n)` supera el límite por defecto (3). Si lo supera, mostrar `"Supera el límite de 3."`; si no, `"No supera el límite de 3."`.

**Ejemplos:**
- `n = 3` → `H(3) = 1.8333` → `No supera el límite de 3.`
- `n = 11` → `H(11) = 3.0199` → `Supera el límite de 3.`

---

## Resolución paso a paso

### Paso 1 — Relación de recurrencia

```
H(n) = H(n − 1) + 1/n
```

Cada término nuevo se suma al resultado de la serie hasta el término anterior.

### Paso 2 — Caso base y caso recursivo

- **Caso base:** `H(1) = 1`
- **Caso recursivo:** `H(n) = H(n − 1) + 1 / n`

> ⚠️ `1 / n` produce un `float` en Python, así que la suma también será `float`, aunque `n` sea entero.

### Paso 3 — Escribir la función recursiva

```python
def armonica(n):
    if n == 1:                          # caso base
        return 1.0
    return armonica(n - 1) + 1 / n      # caso recursivo
```

### Paso 4 — Escribir la función booleana

```python
def supera_limite(valor, limite=3):
    return valor > limite
```

### Paso 5 — Programa principal

```python
def main():
    n = int(input("Ingrese n: "))
    while n < 1:
        print("n debe ser al menos 1.")
        n = int(input("Ingrese n: "))

    resultado = armonica(n)
    print(f"H({n}) = {round(resultado, 4)}")

    if supera_limite(resultado):
        print("Supera el límite de 3.")
    else:
        print("No supera el límite de 3.")

main()
```

### Paso 6 — Verificar con n = 3

- `armonica(3) = armonica(2) + 1/3`
- `armonica(2) = armonica(1) + 1/2 = 1.0 + 0.5 = 1.5`
- `armonica(3) = 1.5 + 0.3333... = 1.8333...`
- `round(1.8333..., 4) = 1.8333` ✅
- `1.8333 > 3`? No → "No supera el límite de 3." ✅

### Paso 7 — Verificar con n = 11

La suma de los 11 términos es aproximadamente `3.0199`. Como `3.0199 > 3`, el resultado es "Supera el límite de 3." ✅

> 💡 Este es un buen ejemplo de por qué la serie armónica crece muy lento: se necesitan 11 términos para superar 3.

### Paso 8 — Puntos a revisar

**¿Por qué el caso base es `n == 1` y no `n == 0`?**
Porque `1/0` no existe. La serie empieza en el término `1/1`, por eso el caso base es `H(1)`.

**¿Por qué `supera_limite` no usa `if`?**
La comparación `valor > limite` ya devuelve `True` o `False`. Igual que en la función `aprueba` del examen 3, un `if` que devuelva esos valores sería redundante.

**¿Por qué se redondea solo al imprimir?**
Porque la comparación con el límite debe hacerse con el valor exacto. Redondear antes podría cambiar el resultado en casos límite.

---

> 💡 **Puntos clave de este ejercicio:**
> - Recursión con caso base que no es `0`.
> - División `/` que devuelve `float`.
> - Función booleana con parámetro por defecto.
> - `round()` aplicado solo en la salida.
> - `if/else` en `main` según el resultado de una función booleana.
