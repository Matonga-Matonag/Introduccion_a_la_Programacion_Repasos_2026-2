# Ejercicio 3: Suma de los primeros términos de Fibonacci

## Enunciado

La serie de Fibonacci se define como:

```
F(0) = 0
F(1) = 1
F(i) = F(i − 1) + F(i − 2)   para i > 1
```

Se pide calcular la **suma de los primeros términos** de la serie, desde `F(0)` hasta `F(n)`:

```
SF(n) = F(0) + F(1) + F(2) + ... + F(n)
```

Implementa las siguientes funciones **recursivas**, sin bucles:

1. `fibonacci(i)`: **con retorno**. Devuelve `F(i)`. Tiene dos casos base (`F(0)` y `F(1)`).
2. `suma_fibonacci(n)`: **con retorno**. Devuelve `SF(n)`. Para calcularla, **debe llamar a `fibonacci`** en cada paso.

El programa principal debe pedir `n` con validación (`while`: si `n < 0`, volver a pedirlo) e imprimir la suma. Luego, con un `for`, imprimir `F(i)` para `i` de `0` a `n`.

**Ejemplo con `n = 5`:**
```
F(0) = 0
F(1) = 1
F(2) = 1
F(3) = 2
F(4) = 3
F(5) = 5
Suma de los primeros términos: 12
```

---

## Resolución paso a paso

### Paso 1 — Separar los dos problemas

Hay dos series involucradas:
1. La serie de Fibonacci, que se calcula con `fibonacci(i)`.
2. La suma de esa serie hasta `n`, que se calcula con `suma_fibonacci(n)`.

Cada una tiene su propio caso base y su propia llamada recursiva.

### Paso 2 — Escribir `fibonacci`

```python
def fibonacci(i):
    if i == 0:                              # primer caso base
        return 0
    if i == 1:                              # segundo caso base
        return 1
    return fibonacci(i - 1) + fibonacci(i - 2)
```

### Paso 3 — Escribir `suma_fibonacci`

La suma de los primeros `n + 1` términos se puede escribir así:

```
SF(n) = SF(n − 1) + F(n)
```

```python
def suma_fibonacci(n):
    if n == 0:                              # caso base: SF(0) = F(0) = 0
        return 0
    return suma_fibonacci(n - 1) + fibonacci(n)
```

### Paso 4 — Programa principal

```python
def main():
    n = int(input("Ingrese n: "))
    while n < 0:
        print("n no puede ser negativo.")
        n = int(input("Ingrese n: "))

    for i in range(n + 1):
        print(f"F({i}) = {fibonacci(i)}")

    print(f"Suma de los primeros términos: {suma_fibonacci(n)}")

main()
```

### Paso 5 — Verificar con n = 5

| `n` | `suma_fibonacci(n)` | Cálculo |
|---|---|---|
| 0 | 0 | caso base |
| 1 | 0 + 1 = 1 | `SF(0) + F(1)` |
| 2 | 1 + 1 = 2 | `SF(1) + F(2)` |
| 3 | 2 + 2 = 4 | `SF(2) + F(3)` |
| 4 | 4 + 3 = 7 | `SF(3) + F(4)` |
| 5 | 7 + 5 = 12 | `SF(4) + F(5)` ✅ |

### Paso 6 — Puntos a revisar

**¿Por qué `suma_fibonacci` llama a `fibonacci` en cada paso?**
Porque necesita el valor de `F(n)` para sumarlo. Esto es composición de funciones con retorno, como en el examen 3, pero una de las dos funciones es recursiva.

**¿Cuántas veces se calcula cada término?**
Mucho más de una vez. `suma_fibonacci(5)` llama a `fibonacci` con los valores `0` a `5`, y cada llamada a `fibonacci(5)` vuelve a calcular todo su árbol de llamadas. Por eso esta solución es correcta pero poco eficiente para `n` grande.

**¿Por qué el `for` del programa principal no es recursivo?**
Porque solo imprime cada término. La recursión se usa solo donde el problema tiene una estructura de subproblemas, como en `fibonacci` y `suma_fibonacci`.

> - Recursión lineal que acumula una suma (`suma_fibonacci`).
> - Una función recursiva que llama a otra función recursiva.
> - `for` con `range(n + 1)` para imprimir los términos.
> - Validación de entrada con `while`.
